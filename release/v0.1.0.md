## 背景

上游 [awesome-gpt-image-2](https://github.com/freestylefly/awesome-gpt-image-2)
有 22 套工业模板 / 541 条案例的知识，但没有执行器；KSkills 有知识漫画的
创作流程，但没有提示词编译器。本插件补齐两端：**确定性提示词编译器 + 出图
执行器**，流程判断仍由会话模型做，插件自身零 LLM 调用。

## 新增

### 双通道与配置面

- **dsh / 麒麟（QiLin）双 manifest**：`package.json` 同时声明 `dsh` 与 `qilin`
  两套 bundle 键，指向同一份 `cordis.patch.yml` 与 `client.js`，一份代码两端可装。
- **设置页「视觉模型」**（配置主入口）：通道管理（类型 / Base URL / API Key /
  模型清单 / 尺寸风格 / 自动回退）、生成默认值、全局负面词、成本阈值与缓存。
  API Key 只存本机 vault（0600），界面永远只回显脱敏串。
- **设置页「图像工坊」**：知识漫画项目清单、逐页产物缩略图、联系表（打印导出 PDF）。
- **插件详情页配置卡**：与设置页共用同一表单，通道列表可编辑 / 测试 / 删除。
- 设置页两个菜单各自**语义字形**（图像框 + 火花 / 漫画分格），不再用壳层通用图标。

### Prompt-as-Code 提示词编译器

- **ImagePrompt v1** 契约：`subject / composition / style / technical / constraints`，
  `composePrompt()` 确定性编译（同输入恒同输出，可测试）。
- 样式库 vendored：22 套模板 / 19 风格 / 10 场景 / 541 条案例，`upstream.lock.json`
  钉住上游 commit 与文件哈希，`sync:upstream:check` 对账防静默漂移。
- 模板避坑指南 → CONSTRAINTS 段落；`constraints.avoid` → 负面清单。
- `sizeStyle` 三形态：像素串（1024x1536）/ 比例 + 分辨率（1:1 + 2k）/ 忽略。

### 工具面（6 个 img_* 工具）

| 工具 | 职责 |
|---|---|
| `img_channels` | 通道总览 / test / probe（含**零成本端点可达性探测**） |
| `img_library` | 样式库检索与模板推荐 |
| `img_compose` | **零成本**编译预览，校验契约 |
| `img_generate` | 编译 → 成本护栏 → 缓存 → 生成 → 落盘 → 记账 |
| `img_batch` | 受限并发批量，预检 dryRun 不花钱，失败不拖垮整批 |
| `img_comic` | 知识漫画项目全流程：open → plan → sheet → render → assemble |

### 知识漫画管线（三锁）

- **文字锁**：角色表逐字进提示词，对白逐字渲染；
- **风格锁**：全篇每页同风格、同前言逐字一致；
- **图像锁**：角色三视图作参考图，跨页形象一致。

### 通道层

- 四种适配器：`mock`（零密钥全链路自检）/ `openai-images`（同步出图）/
  `openai-responses`（Responses + `image_generation` 工具，部分中转只放行此路）/
  `task-images`（异步任务轮询）。
- 三层报价（通道覆盖 > 内置价目 > 未知价），**未知价一律先确认**；`dryRun`
  批量预检不产生费用；结果缓存按内容哈希命中复用；逐次记账可审计。

### 可靠性（真机中转踩坑驱动）

- **端点可达性零成本探测**：以不存在的哨兵模型发必然失败的请求，按响应体是
  JSON 还是 HTML 判定「有没有到达 API 层」——不会出图、不产生费用。
- **错误归因修正**：网关 HTML 403 归为 `ENDPOINT_BLOCKED`（配置问题），
  不再误报「API Key 无效」。
- **端点自动回退**：`openai-images` ↔ `openai-responses` 互换（探测可达才回退，
  首跳在网关被拦未产生费用，无双重计费；通道可关）。
- 通道**原地编辑**（带 id 更新）；更新时 Key 留空表示沿用旧密钥。

## 验证

- 164 项单测（含客户端真实渲染烟测）+ `tsc --strict` 零错误 + 上游数据对账。
- 真机中转（tianyuai.lol）：单图 1024x1536 37.9s；3 页知识漫画《图灵的密码战争》
  4 张图 ¥0.08，**中文对白逐字正确**、跨页角色一致、三视图参考图被接受。
- 自动回退端到端实测：故意配错类型仍 28.9s 出图（1024x1024 PNG）。
- UI 组件用无头 Chrome 按亮 / 暗两套宿主令牌渲染核对。

## 已知限制

- gpt-image-2 系列未内置价目，走「未知价先确认」；可在通道上配价目覆盖。
- `task-images` 适配器协议层完整（含单测），未接真实异步上游跑通过。
- 图像锁参考图依赖通道能力；不支持参考图的通道自动跳过并给出提示。
