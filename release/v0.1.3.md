## 背景

麒麟 3.1.11（新引擎）里，插件在设置页左侧导航中出现了**两个菜单项、两个图标**：
「视觉模型」（order 20，配置）与「图像工坊」（order 21，漫画项目与产物）。

两者其实属于同一个插件、同一件事：通道与生成默认值决定「用什么画」，漫画项目是它的产物视图。
把同一插件的两半拆成两个设置项，既多占一行导航，也让「一个插件一个设置项」的宿主约定失真。

## 修复（`client.js`）

### 一个设置页菜单，页内两个页签

- 只注册**一个** `settings.section`（id `kylin-images`，order 20），导航标签统一为「图像工坊」/ *Image studio*；
- 新增 `SettingsPage` 壳：顶部页签条（`role=tablist` + 两个 `role=tab`）——
  「视觉模型」/ *Vision model*（即原配置页：通道、生成默认值、成本与缓存）与
  「漫画项目」/ *Comic projects*（即原工坊页：项目列表、逐页缩略图、联系表）；
- 默认停在「视觉模型」，与原主入口一致；页签切换只换页内面板，不再新增导航项；
- 旧 id `kylin-images-workbench` 与第二个注册一并删除，避免升级后残留注册；
- 新增页签样式（`.kimg-tabs` / `.kimg-tab`），配色仍全部走宿主别名令牌，亮暗主题自动跟随。

### 导航字形：只留一个，且不叠壳层图标

- 导航字形标记由两个（`data-kimg-nav-vision` / `data-kimg-nav-comic`）收敛为一个
  `data-kimg-nav-images`（图像框 + 火花），`registerNavIcons` 只注册一个观察器；
- **隐藏壳层字形改为「标记行内所有 `svg`/`img` 一律隐藏」**：旧实现只隐藏
  `> svg:first-child` 与 `> span:first-child > svg:first-child`，壳层一旦换一层包裹或改用
  `img`，壳层字形就会和自定义字形叠成「两个图标」。新引擎下这条规则保证标记行只有一个字形。

### 文案

- locale 字典：`nav` 改为「图像工坊」/ *Image studio*，新增 `tabVision`、`tabProjects`；
  删除不再使用的 `workbench` 标签键；插件详情页配置卡（`plugins.bundle.config`）文案不变。

## 验证

- `npm test`：170 / 170 通过（新增/改写 4 条回归：只注册一个 `settings.section`、
  页签切换渲染工坊、唯一导航字形、标记行 svg/img 隐藏）；
- `npm run typecheck`：零错误；
- 真机（麒麟 3.1.11 桌面端）：设置页导航只剩一个「图像工坊」条目、一个图标；
  打开后有「视觉模型」「漫画项目」两个页签，配置与项目功能均可用。
