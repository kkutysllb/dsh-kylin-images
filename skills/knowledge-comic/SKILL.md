# 知识漫画创作器

把知识类文本变成多页漫画。**你不调用任何图像 API**：分析与分镜由你产出，
校验、编译、执行、组装由 `img_comic` 工具完成。

## 何时使用

- 用户要求把一段内容（文章、讲义、传记、教程）画成漫画；
- 用户明确说「知识漫画 / 科普漫画 / 教育漫画 / 传记漫画 / 教程漫画」；
- 用户给出主题但要求成篇的图（而不是单张）。

单张图请直接用 `img_generate`，不要走这条流程。

## 六步流程

1. **内容分析**：受众、核心主题、关键人物与角色弧、戏剧冲突与高潮、最「有画面感」的场景。
   只有主题没有正文时，先整理出 500-2000 字源材料，**让用户确认后再继续**。
2. **开项目**：`img_comic action=open topic="..." source="<源材料>" keywords=[...]`。
   keywords 传内容信号（如「计算机」「教程」「中国历史」），工具按 P0-P10 规则自动选风格/色调/布局；
   用户有明确偏好时用 plan 参数覆盖。
3. **角色设定**：3-8 个主要角色，每个一条外观描述 sheet（年龄/性别/体型/面容/上衣/下装/鞋子/标志性特征/惯用表情）。
   sheet 是跨页一致性的**唯一**依据，越具体越稳；不要写「一个年轻男子」这种模糊描述。
4. **分镜**：每页给 title / core / scene / characters / layout / shot / panels / focus / dialogue。
   节奏建议：封面(0) → 引入(1-2 页) → 展开(主体，每页 1-2 个信息点) → 高潮(1-2 页) → 收尾(1 页)。总页数 5-20。
5. **落盘并编译**：`img_comic action=plan id=... characters=[...] storyboard={pages:[...]}`。
   工具会把每页编译成 ImagePrompt v1 写进 prompts/，并把角色表逐字注入（文字锁）、
   全篇固定同一段风格前言（风格锁）。
6. **出图与组装**：
   - `img_comic action=sheet id=...`：先出角色三视图（图像锁，后续页把它当参考图）；
   - `img_comic action=render id=...`：逐页出图。**成本护栏**：超阈值或未知价会先返回确认请求，
     带 confirm=true 重调；已出图的页命中缓存，不会重复付费。
   - `img_comic action=assemble id=...`：生成 contact-sheet.html（浏览器「打印为 PDF」即得 PDF）。

## 三锁一致性（工具已实现，你只需保证输入质量）

| 锁 | 由什么决定 | 你要做的 |
|---|---|---|
| 文字锁 | 每页注入的 characters[].sheet 逐字一致 | 角色表写细，不要中途改名或改外观 |
| 风格锁 | 项目级 artStyle/tone/layout/宽高比 + 全篇同一句风格前言 | 不要在单页里覆盖 layout 之外的风格字段 |
| 图像锁 | 角色三视图作为参考图注入后续页 | 先跑 sheet 再跑 render；通道不支持参考图时工具会说明 |

## 画面内文字

- 对白/旁白写进 dialogue / narration，工具会逐字锁定并加「必须精确渲染」指令。
- **文字语言与源内容一致**（中文内容就写中文），提示词主体由工具生成英文。
- 短句比长段可靠；一句对白控制在 20 字以内。

## 语言与交付

- 与用户同语言交流；漫画内文字用源语言。
- 交付时说清：总页数、选中的风格/色调/布局与理由、每页一句话简介、成本。
- 产物是文件，用 `read_image` 自评后再交付给用户。
